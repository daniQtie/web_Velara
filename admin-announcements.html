How to Publish
Until a real authenticated CMS is added:
  1. Create the announcement here.
  2. Copy the generated object.
  3. Add it to the ANNOUNCEMENTS array in announcements.html.
  4. Review spelling, dates, links, and image alt context.
  5. Commit the change and verify the deployed page.
Recommended future upgrade: move announcements to Supabase or another datastore, add authenticated admin access, and render public announcements from the same source of truth.
